# Moses Healthcare Facility Management System

A web-based healthcare facility management system for managing patients, doctors, and appointment requests.

## Features

- Patient registration and login
- Patient dashboard with appointment booking and appointment history
- Doctor dashboard to view, confirm, or decline appointment requests
- Admin dashboard to add and manage doctors
- Appointment statuses: Pending, Confirmed, and Declined
- Role-based access for patients, doctors, and administrators

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Local Setup

1. Install and open XAMPP.
2. Start **Apache** and **MySQL**.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create or select the database named `moses_healthcare`.
6. Import the `moses_healthcare.sql` file.
7. Open the application at `http://localhost/moses-healthcare/`.

## User Access

- Patients can register through the application.
- Doctor and administrator accounts are managed through the system's admin portal.

## Database

The project includes `moses_healthcare.sql`, which contains the database structure and data needed to set up the application.
